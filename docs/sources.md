# 资产与依赖

PlayRoom 的公开模块为原项目中筛选出的代码。棋盘 Demo 由 HTML、CSS 和原生 JavaScript 构成，不请求外部字体、图片或脚本。规则与状态机模块使用 Java 标准库，测试依赖 [JUnit](https://github.com/junit-team/junit-framework)（EPL-2.0）。构建使用 [Apache Maven](https://maven.apache.org/)，Node.js Demo 测试使用其内置 `node:test`。

文档结构参考 [GitHub Docs 关于 README 的说明](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-readmes)，未引入第三方作品集模板。此仓库公开用于作品展示，不附加新的开源许可。
