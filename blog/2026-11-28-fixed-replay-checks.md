# 删掉一道错题，通过率涨了多少？

有人给出两份棋谱核对报告。第一份三题答对两题，第二份两题全对。想判断复盘助手有没有改好，可以先把消失的那一道再问一次。

公开网页 Demo 有一盘九手棋。黑棋的第一手在 D8，第七手在 G8，第九手在 H8。这里字母表示列，数字表示行。G8 和 H8 最终都有黑子，所以只看终局上那个格子有没有黑棋，会放过一个很像真的错误。

在仓库根目录依次运行三次核对。每次的两个参数分别是手数和回答声称的坐标。

```sh
node demo/replay-sample.mjs --check 1 D8
node demo/replay-sample.mjs --check 7 G8
node demo/replay-sample.mjs --check 7 H8
```

前两条返回 `match`。第三条输出 `M7: claimed H8, replay G8 (mismatch)`。棋谱确实有第七手，但 H8 要到第九手才落子。还可以运行 `node demo/replay-sample.mjs --at H8 7`，看看当时那个格子是否为空。

现在只保留前两条，报告的通过率就从 2/3 变成 2/2。再单独运行第三条，仍会得到同一个错格。比较两版回答时，保留每题的手数、声称的坐标和实际坐标，两版都跑完同一组，再数哪一条由错变对。这三次调用衡量的是这份固定示例上的坐标核对结果。

命令的退出码也可以用于脚本。坐标相符返回 0，合法坐标与棋谱不符返回 2，缺参数、手数超出棋谱或坐标超出棋盘返回 1。
